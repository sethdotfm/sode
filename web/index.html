                      Forgot the Advanced Settings PIN

                      On the machine running Sode, in the directory with its docker-compose.yml, remove the PIN:

                      docker compose exec sode /sode -reset-pin

                      Then restart Sode to apply it:

                      docker compose restart sode

                      Settings then open without a PIN. Set a new one under Access.
