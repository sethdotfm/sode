No Administrator

Sode has users but no Administrator, so it refuses every Administrator action. On the machine that runs Sode, in the directory with its docker-compose.yml, run this command. It asks for a new PIN.

docker compose exec sode /sode -make-administrator "NAME" && docker compose restart sode

Replace NAME with the name of a user. A new name adds a user, if Sode has fewer than 12.

                  Access

                  Locks Shared settings. Only an Administrator can change them.
                  After 4 wrong PINs for a name, that name waits before the next try. The wait doubles with each wrong PIN, up to 5 minutes. A right PIN stops it. Administrator names always wait.
                  Page locks
                  A locked page asks for a user's PIN before it changes anything. Needs a user (Settings > Users).
                  The Role of a browser with nobody signed in. Guest Rights still limit what it routes.
                  Open access, Standard access or Secured access. It changes the access fields as unsaved changes, and Save shows each one first.
                  Users
                  New user defaults
                  What a new user starts with. Manage users can change it for each user.
                  API The API is always on. A key acts with its owner's Rights. A user can have 50 keys and an API client 200.
                  Lets a call with no key use the keyless scopes, inside Guest Rights (Manage users, Rights tab, Guest). Guest role does not apply to it.
                  Keyless scopes
                  What a call with no key can use.
                  One Communication Log row for every read. Off keeps the log to commands, refusals and key events.
                  0 means none.
                  The router answers one message at a time, so a runaway client is held back here. 1-64.
                  Panels
                  A Public panel opens for anyone with its link, with no sign-in. When this is off, no panel can become Public and each Public panel stops until this is on again. Its pages come back by themselves.
                  The mode a blank new panel starts with. Its owner can change it. Save a copy keeps the mode of the panel it copies. When Public panels are not allowed, a new panel set to Public starts as User.

                  Server

                  Proxy Shared settings. Only an Administrator can change them.
                  Client IPs in history come from X-Forwarded-For only through these.
                  Refuses every request that a trusted proxy did not mark X-Forwarded-Proto: https, except the health endpoints. Needs at least one trusted proxy, and you must save from an HTTPS address. Console reset: sode -reset-https.
                  Export & Import
                  Export Sode to a zip file, item by item: settings, users, presets, panels, artwork and more. Back up everything exports all of it with PINs. An Item link for one preset is in the preset editor.
                  Run setup again
                  Change the name and colour, the router and the access preset in the setup steps. Finish shows each change in the Save review before Sode saves it. It deletes nothing and does not change users.
                  Unsaved changes. Save them, or exit again to discard them.
