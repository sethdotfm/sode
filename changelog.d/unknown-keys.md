- A profile pref that a newer release wrote to config.yaml now survives startup and every profile save. The startup row names it with the other unknown keys.
- Some saves no longer strip keys that this release does not know from every item in the list. These are saves of filter sets, presets, a profile's lists, or users with their rights, API clients and Guest rights.
- After a rollback, Sode keeps the newer release's config.yaml as `config.yaml.unknown-<UTC time>` before the older release saves over it.
