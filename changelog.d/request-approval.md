- Request approval: the Approval popup can send the exact action to the browsers of signed-in users who can approve it. They see a card at the bottom right with the change list and Interruptions, the requester and the browser. Approve asks for their PIN; Deny needs none. You see "Waiting for approval" with a 2-minute countdown and Cancel, and the page stays usable. An edit to what the request covers withdraws it. The button is disabled with "No one signed in can approve this" while nobody qualifies. The Communication Log records each request and how it ended.
