- Import onto another router, more: a filter number or range term gets a row when its names differ in the file. The choices are Keep numbers, Convert to names (the default) and Skip term. Convert to names puts in the file's names as exact-name terms. Use all suggestions, Keep numbers for all blank names and Reset to Skip change many rows at once. The rows are one list: arrow keys move, Space selects, Shift extends, Cmd-click (Ctrl-click) adds, and a drag selects a range. A choice on a selected row goes to all the selected rows. Enter opens the choice and Esc clears the selection. The keys are in the tooltip beside the buttons. With the router offline, the import uses the saved names table and Sode checks the items again when the router answers. With no names at all, an item that holds references is not imported and says why. The others import now. The review lists the changed filter terms.
