- Grid panel editor: on a desktop the page is one window high. The panel's list and Add from the router each keep a fixed part of the column. So an add no longer moves the rows under the pointer. The list's heading counts the rows and pins. An empty list shows an empty state. The actions on the selection are one row of icon buttons. Follow the router (all) is a switch.
- Grid panel editor: in Add from the router, Enter adds the highlighted match and Up and Down move the highlight. Shift+Enter or Add all adds every match. Ctrl+Up and Ctrl+Down also move the selected rows. Icon B runs down the rows in the order the panel draws them, pinned rows first.
- Grid panel editor: the Live Editor shows a Grid panel as its own page does. It has the Levels box, the search boxes, Take and the take confirm.
- Panel editor: the Default levels picker keeps Select All at its full size. A failed read of new router names shows in the status line, and Find reads the names again after a rename.
