- Settings > Access > Locks has Apply an access preset… for an Administrator. It puts the values of Open access, Standard access or Secured access in the form as unsaved changes, each marked with the preset's name. Never sign out and No auto-lock change only for the users you tick. Save shows every change first and asks for one PIN recheck. A preset removes no users, Rights, keys, API clients or panels. If a save keeps some changes unsaved, Settings lists the fields that still differ from the preset and what each one does now. The Settings saves record names the preset.
