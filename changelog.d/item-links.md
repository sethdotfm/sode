- **Item links replace share links.** In the preset editor, Item link shows a link and a QR code for one Everyone or Me preset. Opening it opens the preset popup on that preset. A panel's link in the editor and the Share modal is now its Item link, with a QR code in the Share modal. An Item link works only on the install that made it. On another install it opens nothing and says so. It holds no copy of the item; to move items to another install, use Export. Share links (`#share=` and the old `?f=`) and the Share button in Filters are gone. Each install now has a hidden install UID (`installUid` in the config file), made on first start.
