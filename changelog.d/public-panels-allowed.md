- Settings > Access > Panels has Public panels allowed (on by default) and the new-panel Authentication mode (Public by default). When Public panels allowed is off, no panel can become Public and every Public panel's keys end. A blank new panel starts with the new-panel mode, or as User when that mode is Public and Public panels are not allowed. Save a copy now keeps the mode of the panel it copies. Both fields need a PIN recheck. A rollback to an older release keeps both values in the file as unknown keys.
