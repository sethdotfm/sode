- `POST /api/v1/takes` with a route across routers answers 409 `tie_line_needed` with the ranked tie line paths of each such route. Each path has its hops, cost, Affected destinations and unknown parts. With no usable path it answers 409 `no_path` with each reason. Nothing goes to a router. Settings > Routers > Tie lines has a Hop weight (`tieHopWeight`, default 1), the cost of each hop in the ranking.
