- **Breaking:** `/api/health` no longer has the top-level `router`, `targetAddress` and `err`. `GET /api/v1/status` and its stream frames no longer have the top-level `router`, `routerUp`, `error`, `address` and `err`. A monitor reads `state`, and `routers` for each Router link. `/healthz` only says that Sode answers (`{"server":"up"}`).
- Every router can now set every router setting through the same save. The first router uses the same `router/<uid>/<attribute>` keys as the other routers. The hello sends every setting and the Protects of each router in its `routers` list.
- The status label is one setting for the status bar, `statusLabel` at the top level of `config.yaml`. A file from an older release takes the first router's status label. An older release that reads a file saved by this one shows the address in the status bar.
