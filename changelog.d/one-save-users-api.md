- Manage users and Settings > API have no Save of their own. Their changes show in the review of the Save button of Settings and save with the rest. Closing Manage users keeps its changes until you save or leave Settings. A user, a user's Rights and an API client now save together. Each attribute of a user saves alone, so two people who change different attributes of one user do not overwrite each other. Removing a user in the review names the API clients that go with them.
