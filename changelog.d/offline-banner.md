- The Lost link banner shows This browser, the Sode server and the router with icons. Each link has the same status glyph and word as the top bar: ok, lost or unknown. The lost link is a still line with a gap, and the node past it has the banner's colors swapped. A good link moves a little, and stops when your system asks for reduced motion. The banner gives the reason: the router's last error, or for the Server link the address and the close code. The red outline and the Lock's offline border no longer pulse. The banner no longer says "Reconnecting…". On a phone the banner is smaller.
