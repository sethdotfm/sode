- **Export and import your own items from My user.** Any signed-in user can export their own profile, presets and filter sets to a .zip file and import them again, on this install or another. The other categories show greyed as Administrators only. An import adds and updates your own items and replaces your profile whole; it never changes anything global and never asks for a PIN. The old profile Import & Export dialog, its buttons in the preset editor and the Profile dialog, and the `POST /api/yaml` converter are gone.
