- Export files hold every router of the install. Import maps each router of the file to a router here: the same UID, the same names, the same prefix, or the only router. You can change the target of each router in the Import tab. Items on a router with no target are not imported, and the Import tab says why. Rights lose the references and levels of that router. Restore from a backup in the setup wizard brings back every router with its UID and names.
