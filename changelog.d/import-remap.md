- Import onto another router: in the Import tab, Router names picks a target for each router in the file. It shows how many of the file's names the target has. The first choice is the router with the same UID, then one with the same names table, then the only router. Below it is one row for each source or destination in the file that does not import as is, with what uses it. A name found once at another number moves automatically, under Moved automatically. A name the target does not have starts at Skip. So does a name that is twice on the target, and a blank name. Skip imports the item Broken. A fuzzy match is a suggestion you click. The review shows, for each router pair, how many names are matched as is, moved automatically, chosen by hand and skipped.
