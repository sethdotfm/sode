- Sode now records when each tie line last changed, on any level, by Sode or by another system. It keeps the time on disk beside the saved names tables, so it survives a restart. If Sode was down after that time, or found the change at a re-read, the time reads "before". `GET /tielines` gives `changed` and `before` for each tie line, and the route plan puts the path with the older newest change first.
