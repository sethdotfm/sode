- History shows a tie take as one row for each destination asked for, for example "CAM 1 Via TIE 3 → B MON 42". The row opens to show each hop and what each tie line carried before. Filters and quick search match only the typed source and destination, never the hops. A tie take of one destination stacks with the next change to that destination only when both used the same tie lines. The API gives a caller with hidden visibility null for each hop end that it cannot see, in History and in the take answer.
