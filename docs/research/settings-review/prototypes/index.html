Settings review: prototypes

Static pages with fake data, for RECOMMENDATIONS.md. Each page is one file and makes no outside request. Each page has a Theme switch.

  • Routers: list and detail
    One list of equal routers with link state, and one detail view with every setting. Switch between 1, 2, 12 and 24 routers. Add, remove and reorder routers, set the default router, and read the Save review.
  • Protects at scale
    158 Protects and Router locks on 4 routers: one group for each router, a find box, filters, counts, Free in the row with its result, and Free Sode's Protects by router.
  • Status bar with many routers
    The bar at 1 to 24 routers. It names each lost router by prefix. A click opens a list that leads to that router in Settings.

The pages use the font stack of Sode. If IBM Plex Sans is not on this computer, the browser shows the next font in the stack.
