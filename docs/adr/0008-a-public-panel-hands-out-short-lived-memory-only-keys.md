# A Public panel hands any page a short-lived, memory-only key for its client

A Public panel opens for anyone with its plain URL. The page cannot read a panel's mode before it has a key, so a page with no key posts the panel id alone to `POST /api/v1/panels/{id}/public`, and a Public panel answers with a key for its own client. That key ends 15 minutes on, and the page asks again when a call answers `key_expired` or `key_revoked`. The client's long-lived keys never reach a request that sends nothing else. The key carries the client's Rights (ADR 0006), so the grant never widens.

The route is unauthenticated, so it costs as little as it can. The keys live in memory, not in `keys.json`, so a request never writes to disk. They are bounded at 64 per panel, with the oldest ending first. They have their own shape (`sode_pub.` plus 43 characters), so a key a restart forgot reads as ended (`key_revoked`) rather than as a wrong key, and a wall of tablets behind one address asks again instead of locking itself out. They never show in the instance list or count toward its cap. Every keyless open of any panel asks this route, so a panel that exists and is not Public is not counted against the failed-key throttle. Only an id that names no panel is counted, since that is the guess. Both get the same answer, `200 {"public": false}`, so the route does not say which ids exist.

Considered: handing out one of the client's keys. That puts a key that never ends into any request that names the panel, and switching away from Public would have to find and revoke it. Also considered: a key stored in `keys.json` like a setup link. That writes to disk on every unauthenticated request and fills the instance list and the ended-key list with keys that end every 15 minutes. Also considered: answering 404 for a panel that is not Public. That logs a browser error on every keyless open of a Session panel.

Consequences: leaving Public for any mode ends every key the panel handed out and their streams, not only switching to User, which also removes the client. A Public page's instance stream ends when its key expires and reconnects with the next one, inside the 8 second grace. History names the client, as it does for a keyed link, so the client name is the only trace of who used a Public panel.
